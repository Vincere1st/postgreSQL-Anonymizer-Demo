## Réglementation

Pour rappel, la réglementation européenne (RGPD) impose de protéger les données personnelles des utilisateurs via le Privacy by Default et le Privacy by Design.

## Présentation
PostgreSQL Anonymiser (anon) est une extension PostgreSQL qui permet de masquer les données sensibles dans les requêtes SQL par l'intermédiaire de différentes fonctions de masquage.
